# Selected design

Use the isolated stdlib Python runner from /tmp/semiclosed-config-design/astra.md. Local alternative compiles into legacy Bash but splits initialization/precedence across two languages. Independent reviewer preferred isolated runner8/10 vs6/10. Full parallel model panel unavailable after thread-limit rejection; no further spawns attempted. Review reused a finished non-author reviewer under the capacity fallback. The design is settled.

Data shape: validated RunConfig with TraceSelection, uniform colocated Layout, serving model/engine/acceptance, run settings and paths; resolved RunPlan owns generated artifacts and argv. Model the Domain keeps replica/node arithmetic and week mappings in one place. Separate Before Serializing Shared State keeps all implementation writes in /tmp/inference-sim-semiconfig; parent owns final artifacts/docs.

JSON input only meets user yaml-or-json request without another parser dependency. `semiclosed.sh run CONFIG [--output PATH] [--python EXE] [--dry-run]` plus tiny `semi_closed.sh` alias supports requested spelling. No other legacy semantics change. Config-relative paths, CLI output/interpreter and environment-relative paths relative to caller, repo defaults source/defaults. Version1; strict known wrapper fields/duplicatekeys/nonfinite/types. Week1=May17, fixed16week ordinal map; integer/list/all. All includes complete available weeks and reports unavailable slots; explicit missing fails. Existing old --week directory syntax stays unchanged.

Layout contract: colocated PP1/DP1. Hardware, GPUs per node, TP, replicas; optional fabric and expert parallel flag. If TP<=GPUs per node, require divisibility and derive nodes=ceil(replicas/(GPUs per node/TP)); spare capacity allowed. If TP>GPUs per node, require TP multiple and derive replicas*(TP/GPUs per node) nodes. Multi-node layouts require fabric. Reject PP/DP other than1 if supplied. Pass replicas once as --num-instances and generate matching cluster/pool node counts. Save allocated GPUs, active GPU demand and spare capacity. Existing advanced scenario paths remain available in old commands.

Engine boundary is a small explicit field/type table for demonstrated GLM/DeepSeek native settings, not a copied complete BLIS schema. Native engine spellings retained; unknown fields fail with path. Native BLIS owns model feasibility/memory/cost validation. Include common batch/context/cache/CUDA graph knobs, Engram CPU offload, and DSpark/MTP speculative method/K with explicit category and thinking acceptance selectors. Dry-run resolves config and plans, not hardware feasibility.

Execution: stdlib prepare, no PyArrow import/provision/write in dry-run. Resolve and save actual Python/uv argv; -B prevents pycache. New output only including dangling symlinks; retain original config bytes, resolved config, generated native scenario, argv commands, input conversion, logs, binary, metrics/report, verification. Replay default seed42/no horizon; verifier unchanged. Failure status propagates and preserves artifacts. Source/serving names printed explicitly. Readable CLI errors no silent fallback to GLM.

Implementation owner changes only research/semiclosed/run.py, research/scripts/semiclosed.sh, new research/scripts/semi_closed.sh, and focused tests under research/scripts/tests. Parent adds examples/docs after contract ready and runs original-source verification in primary checkout. No converter or simulator-engine changes.
